# Design

## Mode

Operate: BeGrateful is a repeated-use journaling app, not a marketing page.

## Visual Direction

Quiet, warm, and focused. The interface should feel like a calm daily tool: readable text, generous touch targets, clear controls, restrained surfaces.

## Layout

- Mobile first.
- Primary app navigation lives at the bottom.
- Write is the most prominent action.
- Avoid desktop sidebars for MVP.
- Keep action areas reachable by thumb.

## Components

- Use segmented controls for entry visibility.
- Use fixed bottom actions on writing screens.
- Use simple repeated cards only for entries, reports, and profile summaries.
- Keep nested cards out of the interface.

## Typography

Use a system sans stack. Keep hierarchy compact inside app surfaces; reserve large type for route headings only.

## Color

Use a light neutral base with warm accent colors and a separate trust color for account/security actions. Avoid single-hue pages, purple gradients, and decorative blobs.

## Interaction

Prefer native form controls, visible focus states, optimistic but reversible UI for low-risk actions, and explicit error states for auth, saving, and moderation.

## Accessibility

Minimum touch target: 44px. Form controls need visible labels. Color cannot be the only visibility indicator.
